Recover your account

Lost access to your authenticator?

Sign in with your password, then enter one of the recovery codes you saved when setting up two-factor authentication. Each code can be used once.

Forgot your password?

Use an unused recovery code to set a new password. Afterward, sign in and enter your authenticator code or another recovery code.

If you have no recovery codes

Keep any device where you’re still signed in open. Automated email recovery and a support inbox are currently unavailable. You can continue using the public career tools.
